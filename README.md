An entry for the [news-image-20261124](https://make.fun/bounty/news-image-20261124)
competition on make.fun: sum up 24 November 2026's world news in one image.
The program draws a 1024x1024 newspaper front page — masthead, date, market
ticker strip, a lead panel with a deal-facts box (price, total, premium,
closes), and the day's eight most consequential stories — with its own PNG
encoder and its own 5x7 bitmap font. Python 3, standard library only, no
network, deterministic: two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB).
